Usage: example-personal-site [--port 8080] [--database PATH] [--content DIRECTORY]

Serves a personal site at http://localhost:8080 using twebserver.
The server always binds to 127.0.0.1. Editing and creation are enabled.

On first startup, content/wiki and content/blog seed a SQLite database.
Subsequent starts use SQLite without importing again, preserving browser edits.

Defaults:
  --port       8080
  --database   ./data/personal-site.sqlite3
  --content    ./content when present, otherwise the installed sample content

Paths are relative to PROJECT_HOME under ttrek, or the current directory otherwise.
Stop with Ctrl-C. Run --help to display this message.
