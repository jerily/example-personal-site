Usage: example-personal-site [--port 8080] [--content DIRECTORY]

Serves a read-only personal site at http://localhost:8080 using twebserver.
The local preview server always binds to 127.0.0.1.

Notebook pages come from content/wiki; journal entries come from content/blog.
Edit the Markdown files and restart the server to refresh the content.
There is no browser editor or site database.

Defaults:
  --port       8080
  --content    ./content when present, otherwise the installed sample content

Paths are relative to PROJECT_HOME under ttrek, or the current directory otherwise.
Both wiki and blog subdirectories must exist. Stop with Ctrl-C.
